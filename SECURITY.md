# Security policy

NFM is an early-stage project and is not yet suitable for protecting production systems. Please do not include live credentials, private keys, or sensitive production data in issues.

For a suspected vulnerability, contact the maintainers privately using the security contact configured for the repository before public disclosure. Until a private contact is configured, use the repository's private vulnerability reporting feature if available. Include affected version/commit, impact, reproduction details, and any suggested mitigation. Allow maintainers reasonable time to investigate and prepare a fix.

Never test NFM against systems you do not own or have explicit authorization to assess.
